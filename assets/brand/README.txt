Edgematch 로고 세트 v4 — 아레나 단일 체계 (2026-11-11)
================================================

마크는 아레나 하나뿐이다. 링 없는 마크, 사각 풀블리드 아이콘은 폐기.
모든 SVG는 스트로크·텍스트 없이 채움 패스만 → Illustrator에서 파일 > 열기 로 바로 편집.
워드마크(IBM Plex Sans Bold, 자간 -3%)는 윤곽선화. 형태는 edgemat✱ch — 마침표 자리에 별(0.32em, 베이스라인에 앉힘, 양옆 0.06em). 레이어 ID: ring / edge-left / edge-right / spark / wordmark

색
  Charcoal #2B2D31 (링) · Amber #F2B01E (날) · Spark #E8392B (별) · Ink #161616 · White
  CMYK 근사: Amber 0/30/95/5 · Spark 0/85/85/0 · Charcoal 0/0/0/88

규칙
  밝은 배경 = Y3(차콜 #2B2D31). 어두운 배경 = Y3 -dark(디스크 #34373D, 바탕은 거의 검정). 레드 아레나는 굿즈 전용.
  별은 항상 빨강: 48px 이상 #E8392B, 미만 #FF5A2E(핫 스파크). 흰 별 금지 — 눈송이로 읽힘.
  흑백 아레나는 원판이 아니라 링 선. 원판에 흰 날을 빼지 말 것(흰 종이와 섞여 실루엣 붕괴).
  흑백은 링·날·별이 하나의 패스(fill-rule evenodd). 분리된 도형을 같은 색으로 겹쳐 그리지 말 것 — 접합부에 머리카락 선이 생김.
  별 중심 = 날끝 높이. 별–날 간격 7.7. 여백은 링 두께(9)의 3배 이상.
  크기별 사용: ≥48px 기본(#E8392B) / 24~47px small(#FF5A2E) / ≤24px micro(#FF5A2E). 큰 버전을 그냥 줄이지 말 것.
