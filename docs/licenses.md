# 서체·에셋 라이선스

| 항목 | 라이선스 | 용도 | 출처 |
|---|---|---|---|
| IBM Plex Sans (Bold) | SIL Open Font License 1.1 | 워드마크(윤곽선화된 SVG만 포함, 폰트 파일 미포함) | https://github.com/IBM/plex |
| Pretendard GOV | SIL Open Font License 1.1 | UI 본문·표 (cdnjs에서 웹폰트로 로드) | https://github.com/orioncactus/pretendard |
| Space Grotesk | SIL Open Font License 1.1 | 1차 시안에만 사용, 현재 미사용 | https://github.com/floriankarsten/space-grotesk |

OFL 1.1 요지
- 허용: 상업적 사용, 웹폰트 임베드, 로고·상표 제작 및 등록, 수정.
- 금지: 폰트 파일 자체를 단독 판매, 수정본을 같은 이름(Reserved Font Name)으로 배포, 폰트 파일 재배포 시 라이선스 문서 누락.
- 저작자 표시는 의무가 아니나 이 문서로 출처를 남긴다. "IBM Plex"는 IBM의 상표이므로 IBM의 후원·제작처럼 보이게 쓰지 않는다.

로고 SVG는 Edgematch의 자체 저작물이며, 폰트 글리프는 윤곽선으로 변환되어 폰트 라이선스의 적용 대상이 아니다.
