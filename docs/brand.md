# Edgematch 브랜드 가이드 (v3 · 2026-11-11)

이 문서는 사람과 코딩 에이전트(Claude Code, Codex) 모두가 따르는 정본이다. 값은 `tokens/tokens.json`·`tokens/tokens.css`와 동일해야 하며, 둘이 다르면 tokens가 우선한다.

## 1. 브랜드 한 줄
- 약속: **누구나 전문가처럼 대응하게 한다.** (영업 고도화 SaaS)
- 근거: **어느 브랜드든, 같은 기준으로.** (중립성)
- 로고 콘셉트: 두 절삭날이 VS 포스터처럼 마주 서고, 그 사이 날끝 높이에서 불꽃(*)이 튄다. 격돌을 성사시키는 장(arena).

기하 규칙(200단위 박스): 링 반지름 92. 날은 바깥 변 수직·바닥 여유각 9°·날끝이 최저점(플랭크면 정면), 링 밖에서 들어와 링에 잘림. 별은 세 선 60° 간격·길이 58·두께 12·둥근 끝, 중심 = 날끝 높이(y120), 팔은 절삭날에 수직. 별–날 간격 7.7. 여백은 링 두께의 3배(27) 이상. 크기별: ≥48px 기본 / 24~47px small / ≤24px micro.
배경 규칙: **마스터는 Y3 하나.** 밝은 배경 = 기본(디스크 #2B2D31). 어두운 배경 = `-dark`(디스크 #34373D) — 단, 바탕이 거의 검정(#0E0E0F~#141517)일 때만 디스크가 선다(대비 1.6). 푸른 회색 다크(#1E2023 등) 위에는 올리지 않는다. 별은 항상 빨강(≥48px #E8392B, <48px #FF5A2E). 레드 아레나는 굿즈 전용.
금지: 날을 둥글리기 / 별을 날 위에 겹치기 / 링을 빼고 날·별만 쓰기 / 사각 풀블리드 / 흑백에서 원판에 흰 날 빼기 / 새 색 조합 만들기.
## 3. 색 — 두 영역, 섞지 않는다
**브랜드 색(크롬 전용)**: Ink #161616 · Charcoal #2B2D31 · Amber #F2B01E · Spark #E8392B · Paper #FAFAF8 · Line #E4E2DD.
헤더·푸터·버튼·로고·강조 블록에만. Spark는 주요 버튼과 "매치 성사" 표시에만. Amber는 로고와 차콜 배경 안에서만.

**데이터 색(ISO 513 피삭재군, 표·칩·바·그래프 전용)**: 업계 관습을 따르되 색각 이상자를 위해 명도를 벌린 값.
| 군 | fill | tint | 글자 |
|---|---|---|---|
| P 강 (Steel) | #1F5FC4 | #DCE6F7 | 흰색 |
| M 스테인리스 (Stainless) | #FFD100 | #FFF4BF | 검정 |
| K 주철 (Cast iron) | #B5121B | #F6D6D8 | 흰색 |
| N 비철 (Non-ferrous) | #3FBF7F | #DCF3E7 | 검정 |
| S 내열합금·티타늄 (Superalloys/Ti) | #DD7118 | #FBE4D0 | 검정 |
| H 고경도 (Hardened) | #7A8089 | #E6E8EB | 흰색 |

규칙:
1. 데이터 영역에는 ISO 6색 + 무채색만. 브랜드 3색(Spark·Amber·Charcoal)은 데이터 영역에 들어가지 않는다. 그래서 Spark(빨강)와 K, Amber와 M이 한 화면에 있어도 자리와 모양으로 구분된다.
2. ISO 색은 **항상 글자(P/M/K/N/S/H)와 함께** 쓴다. 색만으로 의미를 싣지 않는다.
3. ISO 범위 바는 항상 P→M→K→N→S→H 고정 순서로 세로 배열한다(위치가 의미를 한 번 더 나른다).
4. 새 색을 추가하지 않는다. 필요하면 이 문서를 먼저 고친다.

## 4. 서체
- UI·본문·표: **Pretendard GOV** (1/l/I, 0/O 구분 글리프, 한·영 혼용 안정). 숫자 열은 `font-variant-numeric: tabular-nums`.
- 워드마크: IBM Plex Sans Bold, 자간 -3% — 로고 파일 안에 윤곽선으로만 존재. 사이트에서 폰트를 불러오지 않는다. 형태는 edgemat✱ch(별이 마침표, 중심 = 베이스라인).
- 라이선스: IBM Plex Sans · Pretendard GOV 모두 SIL OFL 1.1 — 상업·로고·상표 사용 가능. 상세는 `docs/licenses.md`.
- 최소 본문 14px, 표 안 13px. 품번은 UI 서체 그대로(고정폭 불필요).

## 5. 접근성·유니버설 디자인
`docs/accessibility.md` 참조. 요약: 색은 항상 글자·위치·모양과 함께 / 대비 4.5:1 / 키보드 조작 / 호버에만 있는 정보 금지 / 흑백 인쇄에서도 읽힘 / 단위 항상 표기.

## 6. 웹사이트(edgemat.ch) 방향
첫 화면 = 제품 자체(품번 입력창). 무료 도구(절삭조건·경제성·교육)가 입구, 대응 검색이 유료 전환점. 밝은 배경 기본(표 가독성), 차콜은 헤더·푸터·강조 블록, Spark는 액션. 밀도 높게 — 잘 만든 기술 문서에 가깝게. 메뉴·기능명은 영어 고정(Match / Conditions / Economics / Case / Learn), 다국어는 UI만.

## 7. 표기
- 로고·URL: `edgemat.ch` (항상 소문자). `EdgeMat.ch`, `EDGEmat.ch` 쓰지 않음.
- 문장 속 이름: `Edgematch` (첫 글자만 대문자). `EdgeMatch` 캐멀케이스 쓰지 않음.

## 8. 결정 기록 (2026-11-11)
에이전트는 이 기록을 뒤집지 않는다. 바꾸려면 이 문서를 먼저 고치고 커밋 메시지에 이유를 남긴다.
1. 마크는 **아레나 단일 체계**(Y3: 차콜 디스크·앰버 날·빨간 별). 링 없는 마크, 사각 풀블리드 아이콘, 흰 링선 아웃라인은 폐기.
2. 어두운 배경에서도 Y3. 디스크만 #34373D로 올리고, 바탕은 거의 검정(#0E0E0F~#141517). 레드 아레나를 다크 로고로 쓰는 안은 검토 후 폐기(마스터가 둘이 됨).
3. 별은 항상 빨강. 48px 이상 #E8392B, 미만 #FF5A2E. 흰 별은 눈송이로 읽혀 금지.
4. 흑백은 링 선 + 날 + 별을 하나의 복합 패스로(이음새 금지). 원판에 흰 날 빼기 금지.
5. 작은 크기는 small(24~47px)·micro(≤24px) 전용 파일. 큰 로고를 그냥 줄이지 않는다.
6. 워드마크 edgemat✱ch — IBM Plex Sans Bold, 별이 마침표 자리에 베이스라인 중심. 표기는 소문자 edgemat.ch.
7. ISO 513 색은 라이트·다크 두 벌(색각 검증). 데이터 영역에는 ISO 6색 + 무채색만, 브랜드 3색은 크롬에만. A/B 비교는 앰버 실선 / 무채색 점선.
8. UI 서체 Pretendard GOV, 숫자 열 tabular-nums. 다크 테마는 '진짜 다크'(크롬 #0E0E0F, 페이지 #141517, 패널 #1E2023).
9. 레드 아레나는 굿즈 전용, 블랙 아레나는 절제가 필요한 자리 전용.
