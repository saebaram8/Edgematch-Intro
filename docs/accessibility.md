# 접근성 · 유니버설 디자인 규칙

## 왜
- 유럽계 남성의 약 8%가 적록색약. ISO 513의 K(빨강)와 N(초록)이 정확히 그 혼동 쌍이다.
- 현장 사용 환경: 작업복 장갑, 햇빛 아래 태블릿, 흑백 프린터, 노안.

## 색 (시뮬레이션으로 검증: Machado 2009 행렬, protan/deutan/tritan)
- 이전 관습값은 deutan에서 K/N 대비 1.13(구분 불가). 조정값은 K를 어둡게(#B5121B), N을 밝게(#3FBF7F) 벌려 deutan 2.31, protan 4.47.
- 모든 ISO 칩은 글자와 함께. M·N·S 칩은 검정 글자, P·K·H는 흰 글자(대비 4.5:1 이상).
- Spark 버튼은 deutan에서 K·S 칩과 비슷한 올리브색이 된다 → 버튼(둥근 사각 + 텍스트)과 바/칩(표 안)은 모양·자리가 달라 구분된다. 이 분리를 깨지 말 것.
- 흑백 인쇄 시 ISO 바는 명도 순서(M 밝음 → K 어두움)와 글자·순서로 읽힌다. 필요하면 인쇄용 해칭 패턴 옵션을 추가한다.

## 색 외
- 대비: 본문 4.5:1, 24px 이상 큰 글자 3:1. 11px 회색 라벨도 4.5:1.
- 키보드: 모든 조작을 Tab/Enter로. 포커스 링 2px, Spark 색.
- 호버에만 있는 정보 금지(툴팁 내용은 클릭/포커스로도 열림).
- 표: 헤더 고정, 행 높이 ≥ 40px, 터치 타깃 ≥ 44px.
- 단위는 항상 표기(mm/inch, m/min, mm/rev). 소수점은 로케일에 맞춰 입력 허용(쉼표·마침표).
- 숫자 열 tabular-nums, 오른쪽 정렬.
- 언어 전환은 UI 문자열만. 품번·재종명은 번역하지 않는다.
- 움직임: 별(스파크) 등장 모션 1종만, `prefers-reduced-motion` 존중.
- 다크 모드는 선택 사항이며, 제공 시 ISO 색은 그대로 두고 배경만 바꾼다(ISO 색은 빌린 색이라 변주하지 않는다).
